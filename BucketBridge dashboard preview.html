Recovery: Azure back to OCI

Use after an OCI outage. It copies only new or changed files, never overwrites newer files in OCI, and never deletes.

  1. Turn on maintenance mode (top right) so deletes are not mirrored.
  2. Run a dry run and check the file count.
  3. Start the copy and wait for it to finish.
  4. Switch the apps back to OCI credentials.
  5. Run one more copy to catch uploads made during the switch.
  6. Turn maintenance mode off.
